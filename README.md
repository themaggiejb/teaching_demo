## Coding Images
Make sure to check your image follows these guidelines:
    1. PNG format 
    2. Lowercase 
    3. No spaces/Uses - _

Typical image code will look like:

    <img src="image.png"   alt="image" />

However, if in a class, the code will look like:

    url(“background_image.png”);
